03 / SELECTED WORK

Примеры реализованных задач

Что именно было сделано и какой практический результат это дало.

01IAM / MFA

Разделение сценариев MFA по ресурсам

Разделил конфигурации действующей системы 2FA по сервисам и группам ресурсов. Сгруппировал RADIUS-клиентов по типам серверов. Проработал отдельные адаптеры, сценарии аутентификации и политики доступа. Настроил взаимодействие с LDAP/LDAPS и RADIUS/NPS.

Результат: настройки разных сервисов разделены. Для групп ресурсов можно задавать отдельные правила доступа. Изменения в одной конфигурации меньше затрагивают другие интеграции. Новые ресурсы проще подключать по отдельному сценарию.
02VULNERABILITY MGMT

Структурирование активов в MaxPatrol 10

Разделил активы на среды PROD и TEST. Создал статические и динамические группы. Подготовил PDQL-фильтры для отбора систем по ОС, роли и критичности. Проверял результаты аудита и разбирал ошибки сканирования.

Результат: активы разделены по средам и назначению. Можно отдельно контролировать нужные группы серверов, быстрее находить системы с заданными параметрами и точнее выбирать область проверки.
03SIEM / LOGGING

Повышение качества данных для SIEM

Подключал источники событий к RU SIEM: Active Directory, Syslog и Kaspersky. Настраивал коннекторы. Внедрял Sysmon для сбора событий на рабочих станциях и серверах. Оптимизировал логирование AD FS. Анализировал срабатывания корреляционных правил и выявлял ложноположительные события.

Результат: SIEM получает события из дополнительных источников. Sysmon расширяет набор данных для расследований. Анализ срабатываний помогает находить шумные и нерелевантные события.
04NETWORK SECURITY

Сопровождение NGFW Check Point

Полностью сопровождал NGFW Check Point: разрабатывал и настраивал правила безопасности, анализировал и оптимизировал существующие правила, устанавливал прошивки и обновления. Спроектировал и реализовал кластерную конфигурацию для повышения отказоустойчивости сетевого периметра.

Результат: правила NGFW стали более структурированными и эффективными. Кластерная реализация повысила отказоустойчивость сетевого периметра. Обновления поддерживали актуальное состояние платформы защиты.
05ENDPOINT / GPO

Ограничение браузерных расширений через GPO

Подготовил обоснование и план внедрения. Настроил групповые политики Windows с allowlist браузерных расширений. Реализовал централизованное ограничение для корпоративной инфраструктуры.

Результат: установка расширений ограничена утверждённым списком. Это снижает риск использования неразрешённых и потенциально небезопасных дополнений.
06DLP / IR

Обработка DLP-инцидентов и реагирование

Работал с SearchInform КИБ: анализировал DLP-инциденты, настраивал политики контроля съёмных носителей и доступа к ресурсам. При инцидентах ИБ блокировал учётные записи AD, инициировал смену паролей, участвовал в изоляции устройств и блокировке IP на NGFW.

Результат: подозрительные действия с данными передавались на проверку по политикам DLP. Для типовых инцидентов применялись конкретные меры ограничения доступа и сетевой активности.
07SECURITY AUDIT

Технический аудит Windows/Linux-инфраструктуры

Проверял серверы, рабочие станции, учётные записи, сервисы и политики безопасности. Анализировал права доступа и системные настройки с помощью PowerShell и сетевых инструментов. Проверял выполнение внутренних требований и рекомендаций внешнего аудитора.

Результат: выявлялись ошибки конфигурации и несоответствия требованиям. По результатам проверок формировались рекомендации. Сопровождал устранение замечаний.
